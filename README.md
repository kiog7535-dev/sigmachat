# Sigma Chat

  A Discord-inspired real-time chat platform built with Express + Socket.IO.

  ## Setup

  ```
  npm install
  npm run dev
  ```

  Open http://localhost:8080

  ## Default admin account
no

  ## Stack

  - Express 5 + Socket.IO 4
  - express-session + bcryptjs
  - Vanilla HTML/CSS/JS frontend
  - All data stored in database.json (auto-created on first run)
